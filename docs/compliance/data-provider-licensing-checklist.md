# 数据供应商许可检查清单

状态：基线模板  
版本：0.1  
最后更新：2026-08-09

本清单用于供应商接入审批，不构成法律意见。任何 provider 在生产启用前必须由产品、工程和法务共同完成记录。

## 2. 权利范围

- [ ] 允许终端用户屏幕展示；
- [ ] 允许内部临时缓存，并明确 TTL；
- [ ] 允许长期保存历史数据，并明确字段与期限；
- [ ] 允许保存原始响应或仅允许保存派生值/哈希；
- [ ] 允许计算技术指标、评分和其他派生数据；
- [ ] 允许将数据作为 LLM 输入；明确模型提供商是否被视为子处理方/再分发；
- [ ] 允许展示 AI 生成的摘要和引用；
- [ ] 允许向付费用户展示，是否按用户/设备/请求计费；
- [ ] 允许 API、导出、邮件、Telegram 和截图形式分发；
- [ ] 允许回测、基准比较和聚合统计；
- [ ] 允许跨地区处理和存储；
- [ ] 允许在服务终止后继续保留审计快照或必须删除。

任何未明确权利默认视为“不允许”，不得用技术可行性推定授权。

## 3. 来源链和交易所要求

- [ ] 确认 provider 是否为原始来源、交易所授权分销商或再授权方；
- [ ] 记录交易所、新闻社、监管数据库和第三方内容的附加条款；
- [ ] 确认实时/延迟定义、延迟分钟数和展示标签要求；
- [ ] 确认 attribution、logo、链接、版权文本和用户协议要求；
- [ ] 确认用户分类（专业/非专业）及申报、审计义务；
- [ ] 确认指数值、指数成分和指数名称/商标的不同许可；
- [ ] 确认公司公告正文与元数据是否具有不同再利用规则；
- [ ] 确认日本 EDINET、TDnet 及翻译/衍生摘要的具体使用条件。

## 4. 技术与运营限制

- [ ] 请求速率、并发、日/月配额和 burst 限制；
- [ ] 允许的缓存位置、加密、备份和灾备副本；
- [ ] 数据新鲜度、修订、corporate action 和删除通知机制；
- [ ] 禁止混合、反向工程、建立竞争数据库或模型训练的条款；
- [ ] API key 是否可用于多租户 SaaS；生产和开发 key 是否分离；
- [ ] 服务地域、SLA、支持和事故通知时间；
- [ ] 用户删除、合同终止和供应商删除请求的执行方式；
- [ ] provider 是否要求审计日志、使用报告或定期用户数量申报。

## 5. 隐私与 AI 条款

- [ ] 数据中是否含个人信息、作者信息、账户标识或受限文档；
- [ ] provider 是否接收用户查询、IP、portfolio 或其他个人数据；
- [ ] 数据处理协议、子处理方、区域、保留和删除条款；
- [ ] 禁止将用户/供应商数据用于模型训练的配置与合同保证；
- [ ] LLM prompt/response 保留设置满足原始数据许可；
- [ ] prompt logging、observability 和错误追踪不会形成未授权副本。

## 6. 产品行为映射

每个能力必须落到机器可执行 `data_license_policy`：

| 策略字段 | 示例 |
| --- | --- |
| displayAllowed | true/false |
| cacheTtlSeconds | 900 |
| rawRetentionDays | 0 |
| derivedRetentionDays | 365 |
| llmInputAllowed | true/false |
| exportAllowed | true/false |
| notificationAllowed | true/false |
| attributionTemplate | 文本/链接要求 |
| allowedRegions | JP/SG/... |
| contractExpiresAt | RFC 3339 |

adapter 和 snapshot builder 在运行时检查政策；禁止仅依赖团队记忆。许可拒绝使用 `LICENSE_RESTRICTED`，不得自动切换到同样无权使用的数据源。

## 7. 生产启用门槛

- [ ] 合同和所有附加来源条款已归档；
- [ ] 权利矩阵由法务确认；
- [ ] attribution/延迟标签经产品验收；
- [ ] 缓存、保留、导出和 LLM policy 已有自动化测试；
- [ ] 费用、超量和专业用户风险已有监控；
- [ ] 终止/删除 runbook 已演练；
- [ ] 备用 provider 单独完成本清单，不继承主 provider 的结论。

## 8. 当前状态

当前没有生产数据供应商获批。开发必须使用明确许可的测试数据、合成 fixtures 或 mock provider；在许可完成前不得把网络上可访问等同于可商业再分发。
